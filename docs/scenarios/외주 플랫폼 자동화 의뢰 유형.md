# 💼 크몽·숨고 고빈도 업무 자동화 외주 시장 분석 및 기술 구현 지침

> **문서 버전**: v1.0.0  
> **기준 시장**: 크몽(Kmong), 숨고(Soomgo) 프로그래밍 및 외주 개발 카테고리  
> **주요 대상**: 소상공인, 중소기업, 1인 사업가 및 외주 자동화 엔지니어  

---

## 📌 1. 시장 개요 및 트렌드 변화

국내 대표 프리랜서 외주 플랫폼인 **크몽**과 **숨고**의 프로그래밍 카테고리에서 거래되는 업무 자동화 프로젝트는 소상공인과 중소기업의 반복적인 데이터 입출력 수작업을 소프트웨어로 대체하여 운영 비용을 절감하는 실무 영역에 집중되어 있습니다.

### 5대 핵심 도메인 요약
1. **웹 크롤링 및 데이터 수집 파이프라인**
2. **엑셀 VBA 및 Google Apps Script(GAS) 기반 정산·재고 관리 로직**
3. **이커머스 상품 대량 등록 및 마케팅 실행 매크로**
4. **공공 행정 문서(HWP/PDF) 가공 RPA**
5. **생성형 AI API와 노코드 도구(Make, n8n)를 결합한 통합 워크플로우**

### 기술적 중심축의 진화
* **과거**: 단순 데스크톱 마우스·키보드 제어(매크로) 또는 독립 엑셀 파일 내 VBA 함수 작성.
* **현재**: 클라우드 실시간 동기화, 비동기 브라우저 제어 엔진(Playwright), 대형 언어 모델(LLM)을 결합한 자율 에이전트 시스템.
* **가격대 스펙트럼**: 단순 단일 페이지 텍스트 추출이나 기초 수식 매크로는 **3만~15만 원** 선이나, 보안 인증 장벽 우회, 실시간 API 연동, 전용 GUI 패키징을 수반하는 복합 시스템은 **50만~200만 원 이상**까지 확장됩니다.

> [!WARNING]
> **외부 종속성에 따른 시스템 결함 위험**  
> 자동화 소프트웨어는 대상 웹사이트의 UI 구조 변경, 플랫폼 운영사의 봇 차단 알고리즘 도입, 계정 제재 등 외부 환경 변화에 상시 노출되어 있습니다. 따라서 최신 대법원 판례에 부합하는 적법한 수집 설계 기준 확립과 장애 책임 한계를 명시한 계약 구조 수립이 필수적입니다.

## 🏢 2. 현장 발주량이 집중되는 5대 자동화 도메인과 실무 사례

외주 플랫폼 내 수요는 데이터 수집부터 문서 생성 및 외부 서비스 전송에 이르기까지 기업 내부 운영 파이프라인의 특정 병목 구간을 해소하는 데 집중되어 있습니다.

### 2.1 웹 데이터 스크래핑과 실시간 모니터링 엔진 (발주량 최다)
* **이커머스 가격 추적**: 온라인 셀러의 경쟁사 가격 변동, 품절 상태, 프로모션 추적 ➔ 스마트스토어, 쿠팡, 올리브영 대상 모니터링 엔진.
* **마케팅 순위 추출**: 디지털 마케팅 대행사의 네이버 쇼핑 랭킹, 플레이스 순위, 블로그 상위 노출 순위 자동 수집 및 광고 집행 보고서 추출.
* **부동산·경매 실시간 알림**: 네이버 부동산, 직방, 법원 경매 정보 포털에서 면적·호가·권리분석 요약 데이터를 실시간 감지하여 조건 부합 시 텔레그램/슬랙 푸시 발송.
* **B2B 리드 발굴**: 지도 플랫폼 및 공공데이터 포털에서 사업자 상호명, 주소, 유선전화 번호를 지역/업종별로 정제하여 영업 DB 구축.

### 2.2 스프레드시트 업무 로직과 이기종 전산 통합
* **다채널 판매 정산 통합**: 스마트스토어, 쿠팡 윙, 11번가, 자사몰 등 제각각인 판매/정산 내역을 통합하여 주문번호/SKU 기준 행·열 정렬 및 마켓별 수수료·원가 대조 후 순이익 자동 산출.
* **발주서 취합 및 송장 양식 변환**: 각기 다른 포맷의 주문 엑셀/메일을 취합해 통합 발주서를 생성하고, CJ대한통운, 롯데택배 등 택배사 배송 접수 양식에 맞추어 송장 출력용 엑셀로 자동 변환.
* **Google Apps Script(GAS) 협업 봇**: 구글 시트 기입 시 웹훅으로 카카오톡 알림톡 발송, 마감 보고서 PDF 자동 렌더링 후 지정 메일 수신자에게 전송.

### 2.3 이커머스 운영 자동화와 마케팅 액션 매크로
* **오픈마켓 대량 상품 등록**: 도매 플랫폼(도매꾹, 오너클랜 등)에서 수집한 상품의 금칙어 필터링, 검색 가중치 키워드 재배열, 마진율 가산 후 마켓 API 또는 브라우저 제어로 일괄 업로드.
* **콘텐츠 자동 예약 발행**: 워드프레스/티스토리 API 또는 웹 세션 제어를 통한 RSS 피드·뉴스 수집/가공 및 지정 시간 예약 포스팅.
* **소셜/중고거래 모니터링 봇**: 인스타그램 피드, 중고거래 플랫폼의 특정 키워드 게시글 즉각 포착 및 사전 설정된 안내 메시지 자동 발송.

### 2.4 공공 행정 문서 가공과 데스크톱 RPA
* **아래아한글(HWP/HWPX) 대량 렌더링**: 엑셀 명단(수백 명의 인적 사항, 계약 내역 등)을 한글 양식의 누름틀/필드명에 1:1 매핑하여 수료증, 위촉장, 표준계약서 대량 인쇄 및 PDF 변환.
* **금융·세무 표 데이터 파서**: 스캔 이미지나 전자문서(입출금 거래내역서, 카드 명세서, 전자세금계산서 PDF)에서 표 영역을 정밀 인식하여 정형 엑셀 데이터로 구조화.
* **나라장터 입찰공고 알림 봇**: 나라장터(KCONE) 및 지자체 시스템 공고 데이터를 실시간 파싱하여 회사 업종 코드 및 실적 제한 요건에 맞는 사업 공고만 선별해 사내 메신저로 전송.

### 2.5 생성형 AI 파이프라인과 노코드 워크플로우 통합
* **사내 RAG 지식 챗봇**: 제품 설명서, 운영 매뉴얼, CS 가이드 문서를 벡터 DB에 임베딩하고 검색 증강 생성(RAG) 기법을 적용하여 고객 카카오톡 문의나 웹 채팅에 실시간 대응.
* **노코드 SaaS 통합 (Make/n8n)**: 구글 설문지 응답 수신 ➔ OpenAI API 요약/분류 ➔ 노션(Notion) DB 등록 ➔ 슬랙 알림 발송을 하나로 연결.
* **마케팅 콘텐츠 양산 엔진**: 제품 사양표를 입력하면 소구점을 분석해 상세페이지 카피 작성 및 이미지 템플릿 텍스트 자동 렌더링.

### 💡 엔지니어링 실무 팁
1. **Playwright 선호도 급증**: 속도, 리소스 경량화, 네트워크 요청 제어 및 바이패스 기능에서 Selenium을 압도.
2. **한글(HWP) 자동화 표준**: Windows COM 인터페이스를 호출하는 `win32com.client.Dispatch("HWPFrame.HwpObject")` 패턴이 업계 표준.
3. **비개발자 납품 패키징**: 소상공인 의뢰인은 콘솔(CLI) 구동에 거부감이 크므로, **PyQt6/PySide6** 대시보드 UI(프로그레스 바 + 로그 창)를 구축하고 **PyInstaller 단일 `.exe`**로 패키징해 납품하는 것이 정석입니다.

## ⚖️ 5. 최신 판례로 규정하는 법적 책임 및 적법성 판단 체크리스트

자동화 및 크롤링 개발 외주는 기술적 구현의 적법성과 타인의 권리 침해 사이의 경계선이 엄격히 법원에 의해 규율됩니다. 불법 소지가 있는 프로그램을 납품할 경우 개발자는 **민법상 공동불법행위자** 또는 **형법상 방조범**으로 기소될 위험이 있습니다.

### 📋 적법성 검토 체크리스트

| 검토 단계 | 핵심 확인 항목 | 사법적 판단 기준 및 메커니즘 | 위법성 발생 시 적용 법조문 | 개발 실무 대응 조치 |
|:---:|:---|:---|:---|:---|
| **1. 접근 권한** | 비회원 공개 정보 여부 | 기술적 보호조치 없이 URL 입력만으로 열람 가능한지 검토 (*대법원 2021도1533*) | **정보통신망법 제48조 제1항** (무단 침입) | 로그인/유료 결제가 필요한 비공개 영역 수집 의뢰는 **일체 거절** |
| **2. 보호조치 우회** | 캡차(CAPTCHA) 및 IP 차단 강제 우회 여부 | 사이트 운영자가 설치한 객관적 접근 차단 장벽을 무력화하는지 판단 | **정보통신망법 제48조 제1항** 위반 | 강제 우회 모듈(Anti-captcha, 프록시 강제 연동) 개발 배제, 공식 API 권고 |
| **3. 서버 부하** | 단시간 대량 트래픽 유발 여부 | 서버 처리 용량을 초과하여 정상적인 서비스 운영에 장애를 초래하는지 검토 | **형법 제314조 제2항** (컴퓨터등장애업무방해죄) | 요청 간격에 **1~3초 무작위 대기 시간(Random Delay)** 필수 삽입 |
| **4. 데이터 복제 범위** | 원본 DB 전체 또는 상당 부분 복제 여부 | 전체 DB 중 질적·양적으로 상당한 부분을 무단 복제하여 대체재를 만드는지 확인 (*대법원 2023도17354*) | **저작권법 제93조** (데이터베이스제작자 권리 침해) | 단순 사실 정보의 제한적 수집만 허용, **90% 이상 통째 복제 의뢰 수주 불가** |
| **5. 상업적 경쟁** | 경쟁사의 상당한 투자 성과물을 모방하는지 여부 | 막대한 인적·물적 자본이 투입된 데이터를 자사 핵심 영업 자산으로 전용하는지 검토 (*잡코리아 vs 사람인*) | **부정경쟁방지법 제2조 제1호 카목** (성과물 무단사용) | 경쟁 사업 구축 목적의 크롤링 의뢰 반려, 내부 단순 분석용으로 한정 |
| **6. 개인정보** | 연락처, 성명 등 식별 가능 정보 포함 여부 | 공개된 정보라도 당초 공개 목적 외의 영리성 광고 발송 등에 활용되는지 확인 | **개인정보 보호법**, **정보통신망법 제50조** | 개인 식별 정보는 즉시 비식별화 처리하거나 무단 타깃 마케팅용 수집 차단 |

### 📖 핵심 판례 분석 요약
* **정보통신망법 (대법원 2021도1533, 2023도1086)**: 이용약관의 주관적 금지 조항보다 '객관적인 기술적 보호조치(인증, 방화벽)의 존재 여부'가 기준. 로그인 없는 공개 페이지 크롤링은 원칙적으로 침입이 아니나, 캡차 무력화나 세션 위조는 명백한 침입죄.
* **저작권법 (대법원 2023도17354)**: 개별 사실(가격, 상품명)은 저작물이 아니더라도, 전체 DB를 90% 이상 유사도로 실질적 통째 복제하는 행위는 데이터베이스제작자의 권리 침해 유죄.
* **부정경쟁방지법 (잡코리아 vs 사람인, 2017)**: 공개 데이터라도 타인의 상당한 투자 성과물에 무임승차하여 경쟁 서비스를 구축하면 수억 원대 손해배상 책임 인정.
* **업무방해죄 (형법 제314조 제2항)**: 정상 호출이라도 서버 장애를 일으키는 고밀도 트래픽 폭탄은 범죄 성립 ➔ **1~3초 랜덤 딜레이 및 동시 스레드 수 제한 필수**.

## 📝 6. 납품 후 분쟁 방지 외주 계약 및 유지보수 실무

자동화 프로그램은 납품 시점에 정상이라도, 대상 플랫폼의 UI 변경이나 보안 정책 업데이트로 언제든 런타임 오류가 발생할 수 있습니다.

### 1) 하자보수 vs 유지보수 명확한 분리
* **하자보수 (무상)**: 개발자가 작성한 코드 자체의 논리적 오류, 버그.
* **유지보수 (유상)**: 대상 사이트의 HTML DOM 구조 변경, 클래스명 난독화, 신규 캡차 도입, API 엔드포인트 규격 변경.
* ✍️ **계약서 필수 특약 문구**:
  > *"최종 검수 완료 후 대상 사이트의 UI 구조 및 내부 정책 변경으로 인해 발생하는 기능 수정은 소프트웨어 하자가 아니며, 유상 유지보수로 전환되어 별도의 공수 비용이 산정됩니다."*

### 2) 계정 제재 및 IP 차단 면책 조항
* 의뢰인이 프로그램을 오용하거나 과도한 빈도로 구동하여 발생하는 플랫폼(네이버, 인스타그램, 쿠팡 등)의 계정 정지, 서비스 제한, IP 블록에 대해 **개발자의 손해배상 책임이 면책됨을 서면 합의**해야 합니다.

### 3) 산출물 인도 범위와 소스코드 저작권
* 기본 외주 단가(10만~30만 원)는 **단일 실행 바이너리(`.exe`)의 사용권 양도** 기준입니다.
* 소스코드 원본 및 빌드 가이드 문서까지 요구할 경우, 저작재산권 양도 비용을 감안하여 **공급가의 1.5배~2배 이상의 추가 단가**를 책정해야 합니다.
* **월 정기 유지보수(SLA)**: 월 1~2회 정기 점검 및 긴급 사이트 구조 변경 패치를 묶은 구독형 모델로 연결하는 것이 안정적인 수익 확보에 유리합니다.

## 🎯 7. 결론 및 종합 제언

외주 플랫폼 업무 자동화 시장은 단순히 화려한 AI 기법을 나열하는 것보다, **현업의 노동집약적 병목을 오차 없이 제거하는 견고하고 안전한 파이프라인 설계 능력**에 의해 성패가 갈립니다.

1. **사용자 경험(UX)**: 비개발자를 위해 PyQt6/PySide6 기반 대시보드와 `.exe` 패키징을 기본 탑재할 것.
2. **적법성 가드레일**: 대법원 판례 기준(비공개 데이터 수집 거절, 캡차 우회 배제, 1~3초 랜덤 딜레이, 전수 복제 거절)을 엄격히 준수할 것.
3. **계약 안전장치**: 외부 환경 변경에 따른 에러를 유상 유지보수로 분리하고 플랫폼 제재 면책 조항을 확립할 것.
