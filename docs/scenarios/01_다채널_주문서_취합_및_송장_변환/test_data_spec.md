## 2. 포함된 핵심 테스트 케이스 및 검증 포인트

### ① 다채널 주문 건수 1:1 완벽 보존 (100% Row Preservation)
- 쿠팡 4건 + 스마트스토어 4건 + 지마켓 3건 = **총 11건의 원본 주문이 단 1건의 누락/임의 병합 없이 11건의 개별 송장으로 1:1 발행**
- 오픈마켓 판매자 센터(쿠팡 윙, 스마트스토어 센터 등)의 대량 송장 역등록 시스템과 100% 호환

### ② 전화번호 표기법 불일치 정규화 (Phone Number Normalization)
- `010-1111-2222` (표준 하이픈)
- `010.5555.6666` (온점 표기)
- `01077778888` (하이픈 없는 연속 숫자)
- **정규화 목표**: 모든 형식을 `010-XXXX-XXXX` 표준 하이픈 포맷으로 일괄 정규화

### ③ 주소 필드 구조 차이 정제 (Address Field Structuring)
- **스마트스토어**: `기본배송지` + `상세배송지`로 분리된 컬럼 ➔ 하나의 정제된 문자열로 결합 (`{기본배송지} {상세배송지}`)
- **쿠팡/지마켓**: `수하인주소`, `주소` 단일 컬럼 ➔ 다중 공백 단일화 및 특수문자 정제

### ④ 결측치 및 수량 타입 캐스팅 (Missing Values & Types)
- 수량: `"2개"`, `"2"`, `2` 등 다양한 형태를 순수 정수형 `int`로 변환
- 배송메모 누락(공란/None) 시 기본값 `""` 또는 `"부재시 문앞"` 안전 처리
